- Mailbox imports persist physical IMAP identities, then deduplicate CRM projections only with matching participants/content; fetch bounded text parts instead of full attachment MIME to respect hosted resource limits. Independent recent/history cursors prioritize new mail during backfill. Atomic SMTP/APPEND claims and operation deadlines prevent overlapping mailbox leases from duplicating delivery; scheduled callbacks require a private per-run token, never exposed in sales-readable logs.
- ERP mailbox emails use one backend-owned HTML renderer with escaped plain-text bodies and managed signatures; preview uses that same renderer in a sandboxed iframe. Persist rendered text, HTML, signature snapshot and MIME once per outbox operation, so signature edits cannot change retries, Sent copies or CRM deduplication. Signature management is role-checked server-side; transactional/configurator templates stay separate.
